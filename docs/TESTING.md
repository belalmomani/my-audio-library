# حالة الاختبارات (ما نُفِّذ فعلًا وما لم يُنفَّذ)

| الجزء | الحالة | كيف |
|---|---|---|
| `core` (Kotlin/JUnit): التطبيع، منع التكرار (الحالات 1، 2، 3، 5)، الرفع القابل للاستئناف وانقطاع الشبكة (4، 6)، الاستبدال الآمن (8)، تصدير ZIP وفكّه وسلامة الملفات، دمج المكتبات، قص الكلمات والجودة وتقسيم الملفات الطويلة | **نُفِّذت: 48 اختبارًا ناجحًا** | `bash core/run-tests.sh` (أو `gradle :core:test -PcoreOnly`). شُغّلت بمترجم Kotlin 2.0.21 المرفق مع Gradle + JUnit 4.13.2 لغياب Maven هنا |
| مخطط PostgreSQL وRLS (الحالة 7: رفض وصول مستخدم لبيانات آخر؛ منع تكرار الكلمة في المكتبة نفسها والسماح به بين مكتبتين؛ حذف تسلسلي؛ حظر anon) | **نُفِّذ: ناجح** على PostgreSQL 16 محلي | `psql -f supabase/tests/rls_test.sql` (يحاكي auth/uid/الأدوار). لم يُجرَّب على مشروع Supabase حقيقي |
| تطابق التطبيع بين Kotlin وPython | **نُفِّذ: متطابق** على 19 مدخلًا (عربي/تشكيل/تطويل/ترقيم/لاتيني/ligatures) | مقارنة مباشرة للمخرجات |
| الخادم: `tests/test_pure.py` (التطبيع، إسناد الكلمات للمتحدثين، مخزن المهام) | **نُفِّذ: 4 ناجحة** | `python -m unittest tests.test_pure` |
| الخادم: `tests/test_server.py` (FastAPI) | **لم يُنفَّذ** — pip لا يصل إلى PyPI في بيئة الإنشاء | `pip install -r requirements-dev.txt && pytest server/tests` |
| نماذج Whisper / pyannote / Demucs | **لم تُجرَّب** (لا نماذج ولا GPU) | تتطلب بيئة الخادم |
| **تطبيق أندرويد (`app/`)**: الترجمة، Room، Compose، WorkManager، الإعلانات، MediaCodec/Opus | **لم يُترجم ولم يُشغَّل** — لا Android SDK ولا Maven هنا | `gradle :app:assembleDebug` في Android Studio أو CI؛ توقّع أخطاء ترجمة/إصدارات تُصلَح عند أول بناء |
| اختبارات أجهزة (instrumented) | **غير موجودة** | تُضاف بعد أول بناء ناجح |
| Cloudflare R2 وSupabase Auth الحقيقيان | **لم تُجرَّب** | تتطلب حسابات |

لا تعتبر التطبيق «جاهزًا للنشر» قبل: بناء ناجح، وتجربة على جهاز حقيقي بتسجيل عربي طويل، وتشغيل pytest، وتجربة Supabase/R2 حقيقيتين.
